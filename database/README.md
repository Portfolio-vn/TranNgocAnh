# Database

Chưa có database thật — toàn bộ nội dung (thành tích, hoạt động, kỹ năng...) hiện đang hardcode trực tiếp trong [frontend/index.html](../frontend/index.html).

Thư mục này để dành cho sau này nếu cần, ví dụ:
- File JSON/SQLite chứa danh sách thành tích, hoạt động, ảnh... để frontend/backend đọc động thay vì hardcode.
