# Trần Ngọc Anh – Portfolio

## 🌐 Xem trang web tại: https://portfolio-vn.github.io/TranNgocAnh/

Trang portfolio cá nhân (song ngữ Việt – Anh, thiết kế riêng) của học sinh **Trần Ngọc Anh**.

Bilingual (VI/EN) personal portfolio with a unique custom design.

## Cấu trúc thư mục

```
TranNgocAnh/
├── index.html          # redirect sang frontend/index.html (giữ cho GitHub Pages, vì Pages chỉ serve từ root)
├── frontend/            # toàn bộ trang tĩnh
│   ├── index.html
│   ├── css/style.css
│   ├── js/script.js
│   └── assets/img/
├── backend/             # chưa dùng — để dành cho sau này (xem backend/README.md)
└── database/            # chưa dùng — để dành cho sau này (xem database/README.md)
```

Site hiện tại 100% tĩnh, không có server hay database thật đứng sau. `backend/` và `database/` chỉ là chỗ trống, dự phòng cho tương lai.
